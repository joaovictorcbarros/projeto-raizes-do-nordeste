# 🌵 Raízes do Nordeste -  Projeto Front-End

Este Projeto Multidisciplinar foi desenvolvido para atender às demandas de uma rede de lanchonetes em expansão. A aplicação tem como foco fornecer uma interface clara, coerente e otimizada para múltiplos canais de atendimento.

---

##  Funcionalidades e Requisitos Atendidos

A interface foi projetada para garantir uma excelente jornada do usuário, contemplando as seguintes regras de negócio:

* **Cardápio Dinâmico e Carrinho:** Visualização de itens e gerenciamento de pedidos simulados no navegador.
* **Autenticação Simulada (Mock Auth):** Sistema de login utilizando *mock data* para (Acesso Teste) agilizando o processo de testes e avaliação, além de permitir o cadastro manual.
* **Conformidade com a LGPD:** Avisos de privacidade explícitos e consentimento claro para o uso de dados integrados visualmente na interface.
* **Processamento de pagamento via gateway externo:** Telas de simulação para o envio de pagamentos com (Pix, Cartão, Dinheiro) e retorno visual, respeitando a regra de processamento externo.
* **Acompanhamento do status do pedido:** Sistema do fluxo dos "Pedidos Recebidos", para o cliente, com atualização clara dos status: "Em preparo", "Pronto" e "Entregue".
* **Sistema de Fidelidade:** Acúmulo e uso de "CoinsRaízes" renderizados dinamicamente na conta do cliente.
* **Design Mobile-First:** Responsividade total para adaptação em smartphones, tablets e desktops (Web/App/Totem).

---

##  Tecnologias Utilizadas

* **HTML5:** Semântica e estruturação.
* **CSS3:** Estilização global e media queries para responsividade.
* **JavaScript:** Lógica de negócio, validação de formulários, manipulação do DOM e persistência de dados utilizando a API do `localStorage`.

##  Como testar o projeto?

Para testar os fluxos principais do projeto, sem a necessidade de criar um cadastro do zero, siga os passos abaixo:
1. Acesse a tela de **Entrar**.
2. Clique na opção **"Acesso Teste"** no canto inferior direito.
3. No Pop-up que abrir, selecione um dos perfis já pré-configurados (João ou Anne) e por fim clique em **Entrar**.
4. Navegue pelas opções de cardápio, fidelidade, carrinho e simulação de pagamento, do checkout até a entrega do pedido.
